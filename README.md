# APROAR · Gestão de Equipes

Versão web oficial do sistema de gestão de equipes da APROAR.

- Frontend estático hospedado no Netlify
- Netlify Functions para autenticação e APIs
- Neon PostgreSQL para persistência
- GitHub como fonte oficial do código

A lógica funcional deve permanecer fiel ao sistema Python de referência `helenacsss2002/sistema-equipes-aproar`.
